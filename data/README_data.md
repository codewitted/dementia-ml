# Data Directory Structure

- `data/raw/clinical.csv`: Clinical/demographic spreadsheet from OASIS-1
- `data/raw/Mild Dementia/`: Folders of MRI (.jpg or .nii) slices for diagnosed class
- `data/raw/Non Demented/`: Folders for control group
- (Others as available, e.g. Moderate Dementia)

**Download OASIS via Kaggle or the official site, and place files as above.**

**DO NOT push raw data to GitHub. Use only scripts and instructions here.**
